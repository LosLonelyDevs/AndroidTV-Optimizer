# Android TV Optimizer assets

- `android-tv-optimizer.svg`: original vector logo, extracted from `v2/src-tauri/icons/source.svg`. Scales without losing detail.
- `android-tv-optimizer-1024.png`: original 1024×1024 app icon. No upscaling.
- `screenshots/`: current desktop screens using offline demo data, not a connected TV.

Run `npm run screenshots` from `v2/` to regenerate both theme galleries and refresh these files. The release workflow commits the refreshed assets alongside the galleries.
